# Protected Kernel Guide (Operator/Public-Safe)

## Purpose

This guide explains how to use RepoBrain safely without exposing protected kernel internals.

## What You Can Trust

- deterministic route/execution categories in artifacts,
- explicit governance outcomes,
- compact user-facing output,
- public-safe and operator-safe evidence separation.

## What You Should Not Expect in Public Docs

- internal kernel architecture details,
- internal module/file disclosures,
- reverse-engineering-oriented implementation descriptions.

## Operational Focus

For day-to-day usage, focus on:

1. readiness validation,
2. supported command surface,
3. artifact interpretation,
4. explicit unsupported behavior.

- `docs/USER_GUIDE.md`
- `docs/OPERATOR_QUICKSTART.md`
- `docs/EXTERNAL_MODE.md`
- `docs/MCP_SURFACE.md`
