# Distribution Boundaries (Pre-Marketplace)

## Current Distribution Position

RepoBrain is pre-marketplace and pre-GA.

The current packaging layer supports repeatable handoff and operator onboarding for accepted bounded surfaces only.

## Explicitly Supported Today

1. GitHub mode: ask/review/fix within accepted governance and readiness boundaries.
2. External GitHub mode foundation: doctor/help/ask plus bounded read-only Review Candidate and bounded Fix-Lite Candidate manual-only patch suggestion.
3. External mode (CLI): ask-only.
4. MCP surface: ask-only.

## Explicitly Not Supported Today

1. Patch application, file modification, commit creation, branch pushing, or PR creation in the external public surface.
2. Broad MCP capability expansion beyond ask.
3. Marketplace/admin/billing product surfaces.
4. Full external GitHub-native review/fix parity claims.
5. Security verdicts, safe-to-merge claims, and approval/rejection verdicts.

## Claim Discipline

Outward-facing materials must:

1. state supported surfaces explicitly,
2. state unsupported surfaces explicitly,
3. avoid roadmap-as-fact wording,
4. avoid protected-kernel disclosure.

## Expansion Rule

Any unsupported-to-supported transition requires:

1. explicit sprint scope,
2. required review class from governance matrix,
3. live validation evidence before acceptance.
