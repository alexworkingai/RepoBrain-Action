## License Name

`RepoBrain Action Source-Available BYO-LLM License v0.2`

## Source-Available, Not OSI Open Source

RepoBrain-Action is source-available software.
It is not released under an OSI-approved open-source license in the current product stage.

## BYO-LLM Model

RepoBrain is not an LLM reseller.
Users bring their own LLM, model, API, or provider access.

Users may use:

- free GitHub-hosted or GitHub Models access
- paid GitHub Models billed to the user''s own GitHub account
- Azure OpenAI, OpenAI, Anthropic, or other providers through the user''s own accounts
- their own BYOK provider or model configuration

## User-Paid LLM Costs

All model, quota, API, and provider costs are the user''s responsibility.
RepoBrain does not include, resell, subsidize, guarantee, or bill for model usage.

## Free, Evaluation, And Internal Use

The license allows use, viewing, and internal modification for:

- self-use
- evaluation
- private beta
- internal repository automation

Paid LLM usage through the user''s own provider account is allowed for the user''s own internal repositories.

## Commercial, Hosted, Managed, And Resale Restrictions

Commercial resale, hosted-service use, managed-service use, SaaS use, client-facing paid service use, sublicensing, or redistribution as a competing product requires separate written permission.

## TopoCore v6 Source Exclusion

TopoCore v6 source code is permanently excluded from the RepoBrain-Action license.
No TopoCore v6 source-code rights are granted through RepoBrain-Action.
Authorized runtime access, if provided separately, does not grant source rights.

## No Warranty

RepoBrain-Action is provided as-is, without warranty.
Its outputs are not represented as security approval, legal approval, merge approval, or risk-free certification.

## Why Not No-License

A no-license posture would make even legitimate evaluation and internal beta use legally unclear.
The source-available license keeps the permitted private-beta and internal-use path explicit.

## Why Not MIT Or Apache Today

RepoBrain-Action depends on a permanently private TopoCore v6 boundary and a controlled product strategy.
A permissive OSS license would not match the current commercial, dependency, and proprietary-boundary decisions.
