# Service And Commercial Model

## RepoBrain Is Not An LLM Reseller

RepoBrain does not resell model tokens or provider access.
Users bring and pay for their own LLM, API, and model accounts.

## Users Bring And Pay For Their Own LLMs

Supported model-provider shapes may include:

- GitHub Models free or rate-limited access
- paid GitHub Models billed to the user''s GitHub account
- Azure OpenAI through the user''s own account
- OpenAI through the user''s own account
- Anthropic or other providers through the user''s own account
- BYOK model/provider configuration

## Free And Evaluation Use

The near-term product path supports:

- self-use
- evaluation
- internal repository automation
- private beta partner use

## Team, Pro, And Enterprise Direction

Possible future paid value is not token resale.
Potential paid or commercial offerings may include:

- repository audit and scoring
- enterprise onboarding
- support
- private TopoCore runtime access
- custom governance profiles
- custom evidence and ranking profiles
- GitHub Enterprise or Azure integration
- managed deployment later
- SLA and support contracts later

## Microsoft And GitHub Strategic Attention

Near-term business priority is not aggressive monetization.
The higher-value near-term outcome is adoption proof and strategic attention from Microsoft and GitHub around GitHub-native repository intelligence, scoring, governance, and evidence-grounded automation.

## Immediate Commercial Posture

- no token resale
- no bundled model billing
- no implied hosted service rights under the source-available license
- controlled private beta while product positioning and distribution strategy mature
