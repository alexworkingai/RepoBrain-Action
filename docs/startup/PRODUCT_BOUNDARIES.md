# Product Boundaries (Startup Stage)

## Supported Claims

RepoBrain may be presented as:

- a governed repository cognition runtime,
- externally evaluable at startup stage,
- primary in GitHub mode,
- bounded in external and MCP ask-first surfaces.

## Unsupported Claims

Do not claim:

1. Marketplace launch readiness.
2. Admin/billing portal availability.
3. External review/fix support.
4. MCP capability breadth beyond ask.
5. Full external GitHub-native runtime parity.

## Messaging Guardrails

1. Prefer capability truth over roadmap language.
2. Mark unsupported behaviors explicitly.
3. Keep public wording protected-kernel-safe.
4. Avoid implying GA/distribution maturity not yet reached.

## Boundary Escalation Rule

If an external request requires unsupported capability, stop and escalate rather than improvising a pseudo-supported path.
