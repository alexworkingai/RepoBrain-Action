# Competitive Positioning (Bounded, Evidence-Based)

## Positioning Rule

This comparison is concise and factual.  
It highlights where others are stronger and where RepoBrain is differentiated today.

## Quick Comparison

| Product | Typical Strengths | RepoBrain-Relevant Difference |
|---|---|---|
| GitHub Copilot | Deep IDE/platform integration, broad developer adoption | RepoBrain focuses on governed repository-runtime behavior with explicit bounded/unsupported outcomes and audit-first operational framing. |
| Anthropic Claude Code | Strong coding assistance workflow and fast iteration UX | RepoBrain emphasizes explicit governance + bounded capability disclosure + operator artifact discipline over broad capability narrative. |
| Cursor | Fast interactive coding experience in editor-centric flow | RepoBrain differentiates on repository/process governance surfaces and explicit readiness/evidence boundaries for team operation. |
| Sourcegraph | Enterprise code intelligence and repository-scale navigation | RepoBrain differentiates as a bounded execution/control layer for governed ask/review/fix workflows rather than broad search/insight platform scope. |

## Where RepoBrain Is Strong Today

1. Honest supported/unsupported boundaries.
2. Operator-readable readiness and escalation discipline.
3. Public-safe artifact-backed decision visibility.
4. Protected-kernel-safe outward product shell.

## Where RepoBrain Is Not Claiming Leadership

1. Broad feature breadth.
2. Marketplace-scale distribution maturity.
3. External review/fix capability parity.

## Strategic Interpretation

RepoBrain is currently best framed as a trust/control layer complement to broader assistants, not a direct breadth-first replacement.
